# Changelog

All notable changes to this project will be documented here.

## [0.1.0] - 2026-06-03

### Added

- Initial public release of the Polymarket Research Toolkit.
- Paper-first operator menu, controlled run workflow, and post-run reports.
- Low-latency data ingestion across Polymarket, Binance, Coinbase, and public
  Chainlink RTDS sources.
- Strategy research profiles, local analytics, PolyBacktest helper scripts, and
  wallet replay tooling.
- Maintainer documentation, contribution policy, roadmap, security guidance,
  issue templates, and pull request template.

### Notes

- This release is for research, simulation, and paper trading only.
- No strategy profile should be considered proven profitable without independent
  out-of-sample validation.
