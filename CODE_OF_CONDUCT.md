# Code of Conduct

This project welcomes careful, evidence-driven collaboration.

## Expected Behavior

- Be respectful and constructive.
- Focus criticism on code, data, assumptions, and reproducibility.
- Be clear when something is speculation rather than measured evidence.
- Help keep issues and pull requests actionable.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Sharing private keys, API keys, wallet secrets, or sensitive logs.
- Encouraging market manipulation, wash trading, spoofing, platform bypasses, or
  use of non-public information.
- Presenting unvalidated strategy results as guaranteed profit.

## Reporting

Open a GitHub issue for normal project concerns. Do not include secrets or
sensitive trading credentials in public issues. If a report requires sensitive
details, first open a sanitized issue asking maintainers how to coordinate a
private reproduction.
